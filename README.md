# 居家管家 Home Manager ♡

一款粉桃色系、桌面吉祥物陪伴的 Windows 桌面小管家：闹钟、定时任务、日历日程（含农历/节气/节日）、番茄钟、资源集市、一键早安，全部离线可用，并支持简体中文 / 日本語 / English 三语切换。

## 功能一览

- **闹钟**：按星期重复、贪睡、自定义铃声与闹钟背景、全屏置顶弹窗；支持睡眠唤醒（RTC 定时器，需在设置里开启）。
- **定时任务**：定时提醒（如吃药）、定时启动程序并自动点击指定位置。
- **日历日程**：月历双击添加日程；内置 1900–2100 农历、二十四节气、中外节日；键盘方向键选日期；下一个节气/节日倒计时。
- **纪念日倒数**：支持公历与农历日期、每年重复，日历格子带 ♡ 标记，当天自动弹窗提醒。
- **番茄钟**：25/5 循环（时长可调）、圆环倒计时、完成统计、吉祥物鼓励、完成时播放轻柔风铃。
- **每日日语**：闹钟页每日一个日语单词（离线词库，按日期轮换），早安简报同步播报。
- **一键早安**：关闭起床闹钟后弹出今日简报（日期、农历节日、今日日程、日语单词），并可按顺序自动打开你指定的程序。
- **资源集市（联网）**：
  - 可爱壁纸/插画：来源 [nekos.best](https://nekos.best)（SFW 免费接口，无需密钥），一键设为闹钟背景或吉祥物；
  - 铃声白噪音：内置离线合成的雨声、海浪、粉噪、轻柔风铃，可试听、设为默认铃声；
  - 吉祥物装扮：选择本地图片作为侧边栏吉祥物，随时恢复自带；
  - 通用链接下载：粘贴任意图片/音频链接，音频自动归入铃声库。
- **设置**：开机自启、唤醒提前量、语言、铃声、背景、早安程序、检查更新。
- **后台运行**：关闭窗口最小化到系统托盘，闹钟照常工作。

## 界面预览

主界面为左侧导航 + 右侧卡片式页面，所有切换均为 120ms 缓动动画，只有点击的控件有反馈，不整页闪烁。

## 直接使用（便携版）

1. 到 [Releases](../../releases) 下载 `居家管家-vX.X.X-portable.zip`；
2. 解压到任意目录（**不要放在 `Program Files` 等需要管理员权限的目录**）；
3. 双击 `居家管家.exe` 运行，数据保存在程序同目录的 `data\` 文件夹，复制整个文件夹即可迁移/备份；
4. 在「设置」里可以开机自启、检查更新。

## 从源码运行

需要 Windows 10/11 + Python 3.10 及以上（开发环境为 Python 3.14）。

```powershell
pip install pillow pystray
pythonw home_manager\main.pyw
```

也可以使用根目录的 `启动居家管家.bat` 或 `静默启动居家管家.vbs`（无控制台窗口）。

## 构建便携版

```powershell
powershell -ExecutionPolicy Bypass -File .\build_release.ps1 -Python "C:\路径\python.exe"
```

产物：

- `home_manager\dist\居家管家\`：可直接分发的文件夹；
- `home_manager\dist\居家管家-vX.X.X-portable.zip`：上传到 Release 的压缩包。

## 在线更新机制

1. 在 GitHub 创建公开仓库并推送代码；
2. 发布一个 Release，Tag 形如 `v1.2.0`，并把构建出的 zip 作为附件上传（附件名需以 `.zip` 结尾）；
3. 编辑 `home_manager\config.py`，把 `GITHUB_REPO` 改为 `"你的用户名/仓库名"`，重新打包发布；
4. 之后用户在「设置 → 检查更新」即可发现新版本；便携版会自动下载 zip、替换文件并重启（开发环境下直接打开发布页）。

## 目录结构

```
居家管家/
├─ home_manager/
│  ├─ main.pyw            # 入口
│  ├─ config.py           # 路径/版本/默认设置（打包兼容）
│  ├─ storage.py          # 数据存取 data/data.json
│  ├─ scheduler.py        # 闹钟/任务/日程/纪念日调度
│  ├─ holidays.py         # 农历、节气、节日（离线）
│  ├─ anniversaries.py    # 公历/农历倒数日
│  ├─ nihongo.py          # 每日日语词库
│  ├─ ambient.py          # 白噪音/风铃离线合成
│  ├─ net.py / updater.py # 联网下载 / GitHub 更新
│  ├─ morning.py / ui_morning.py
│  ├─ ui_*.py             # 界面（主窗口/各页面/弹窗/对话框/样式）
│  └─ assets/             # 图标、吉祥物、默认背景铃声、音频库
├─ build_release.ps1
└─ 使用说明.md
```

## 说明

- 联网图片由 nekos.best 的公开 SFW 接口提供，版权归原作者所有，资源集市仅提供个人收藏入口。
- 「睡眠唤醒」只能把电脑从睡眠/休眠中唤醒，**无法给完全关机的电脑开机**；需要配合主板 RTC 定时器，设置页有引导。
- 完全关机后自动开机如需更可靠，可在主板 BIOS 设置 RTC Alarm。
